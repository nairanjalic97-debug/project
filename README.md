# Project

A development environment setup for working with AI-assisted coding tools in Cursor.

## Tools Installed

- **Cursor** - AI-powered code editor
- **Claude Code** - Claude extension for Cursor
- **Codex** - OpenAI Codex extension for Cursor
- **Git** - Version control (installed during repository setup)

## Setup Steps Completed

1. Created a GitHub account
2. Created a public repository named **Project**
3. Added an initial `README.md` file on GitHub
4. Installed **Cursor** and signed in via GitHub
5. Cloned the GitHub repository into Cursor
6. Installed the **Claude Code** and **Codex** extensions in Cursor

## Issues Encountered and Solutions

### Cloning the GitHub repository

**Issue:** Cloning the repository failed initially. The SSH clone (`git@github.com:...`) did not work due to host key verification errors, and Git was not installed on the system.

**Solution:** Used the Cursor agent to resolve the problem. The agent installed Git, then cloned the repository successfully using HTTPS (`https://github.com/nairanjalic97-debug/project.git`).
